v4 이후 바뀐 내용은 **`CHANGES_v5.md`** 에 정리했습니다. v1~v4 리뷰 대응 기록은 `REVIEW_RESPONSE.md` 에 그대로 둡니다.

- 수집 기준일: 2026-09-17 (op.gg Champions 도감·랭킹) — v4와 같은 원천입니다. 바뀐 건 모델과 파이프라인뿐입니다.

## 재현

```bash
cp -r input/raw2 input/mvraw input/tier_new.txt code/
cp input/seed/* code/
cd code && ./rebuild.sh
```

전체 1시간 남짓 걸립니다(`opt_mo.mjs full` 약 8분, `nash_mo.py` 풀마다 약 18분).

## 모델 요약

```
st(b)=b+52   hp(b)=b+107                ← 6스탯 동시 252 (실전 불가능한 가정. config.evMode 로 민감도 확인)
damage = (⌊⌊22·위력·공격/방어⌋/50⌋+2) × 자속 × 타입 × 특성 × 아이템 × 랭크업
        · 연속기는 타수만큼(트리플악셀 120, 2~5회기 ×3.1, 스킬링크 ×5)   ← v5
        · 바디프레스는 자기 방어로                                     ← v5
        · 메가는 자기 특성(스카이스킨·페어리스킨 포함)                  ← v5 직전(09.19)
turns  = ceil(HP_eff / damage)           ← 최대 화력 가정 (config.mix = 0)
o = clamp(((n_j − n_i) + 선공)/3)    d = clamp((n_j − 평균)/평균) × 위협도게이트    v = 0.7·o + 0.3·d
상대 j 는 실효 메가 확률 EFF[j] 만큼 메가:  v' = (1−EFF)·v(기본형) + EFF·v(메가)
```

팀 탐색은 `V_blend_oppmega` 로 상위 2장 평균을 최대화하고(6.2억 조합), 후보 450팀은 **양쪽 다 "3마리 × 누가 메가하나"를 수로 갖는** 행렬 게임을 래더 149팀 각각에 대해 LP로 풀어 평균합니다.

## 결과 해석 시 주의

모든 "최적/추천"은 위 가정 아래의 **후보**이지 실전 승률 예측이 아닙니다. 교체·상태이상·필드·압정·리드 선택이 없고, 팀 점수는 3×3 아홉 쌍의 1:1 값 평균입니다. 조우 가중치는 op.gg 순위가 아니라 **래더 149팀 표본의 실제 출현**에서 옵니다(보만다 op.gg 1위 → 표본 16팀, 한카리아스 2위 → 63팀). 래더 표본 3회 이하 카드(에이스번·저승갓숭·잠만보 등)의 값은 검증이 아니라 외삽입니다 — `14_sample_vs_model.csv` 를 같이 보세요.
