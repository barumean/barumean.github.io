# v4 → v5 변경점 (2026-09-18 ~ 09-21)

원천 데이터(09-17 수집)는 그대로입니다. 바뀐 건 모델과 파이프라인입니다. 날짜 순서대로 적습니다.

## 1. 팀 추천이 상대를 기본형으로만 보고 있었다 — 버그 (09-19)

- **증상**: 추천 팀(브리두라스/갸라도스/에이스번/찌르호크/잠만보/저승갓숭)이 op.gg 1위 보만다에게 **답 0장**. 제일 나은 카드가 −0.03, 나머지 −0.19 ~ −0.80.
- **원인**: 상대 6마리 대조 화면은 상대 메가를 다뤘지만, **조합 탐색(`opt_*.mjs`)과 내시 균형(`nash_*.py`)은 상대 100종을 전부 기본형으로 계산**. 41종이 스톤을 95~99% 채택한다.
- **수정**:
  - `mkeff.mjs` — 종별 **실효 메가 확률**. 상대도 경기당 메가 1회라 채택률을 같은 팀 스톤 보유자끼리 나눈 값의 래더 표본 평균. 팀당 평균 스톤 2.72장 → 실효 47~66% (보만다 채택 97.7% → 실효 47%).
  - `opt_mo.mjs` — `opt100b/opt_full/opt_obs.mjs` 대체. 실효 메가 확률로 섞은 값으로 탐색.
  - `nash_mo.py` — `nash100/nash_full/nash_obs.py` 대체. **양쪽 모두** 수 = "3마리 조합 × 그중 누가 메가하나".
  - `mkv2.mjs` 가 `V100o.json`(상대 메가), `V100mm.json`(둘 다 메가)을 추가로 만든다.
- **효과**: 조우가중 1:1 평균 −0.093 → −0.160. 팀 대리점수가 일률적으로 약 0.09 부풀려져 있었고, **1위 팀이 바뀜**.

## 2. 메가가 기본형 특성을 쓰고 있었다 — 버그 (09-19)

- 메가보만다가 **스카이스킨** 대신 기본형의 **위협**을 물려받고 있었다. 채용 1위 기술 이판사판태클(81%)이 자속 없는 노말기로 계산.
- `config.mgAb=1` — 메가는 자기 특성. `-스킨` 계열(스카이·페어리·프리즈·일렉트릭)을 데미지 모델에 추가. 기본 특성에도 적용되어 **님피아 페어리스킨**도 이제 반영.
- 고친 뒤 메가보만다에게 값 0 이상인 카드는 100종 중 2종.

## 3. 반동기 — 구현했지만 팀 모델에서는 끔 (09-19)

- `config.recoilK` (기본 0). 1:1 끝장 싸움 틀에서는 교체·회복 타이밍이 없어 과하게 쌓여 ρ50 0.502 → 0.480, 보만다 모델 순위 1위 → 9위.
- **기술 추천에서는 켬** — 반동기끼리/반동기와 일반기를 비교할 때 반동이 곧 비용이기 때문(§6).

## 4. 무답 위협 · 단일 추천 · 메가스톤 1장 (09-19 ~ 09-20)

- **무답 노출** = 그 상대에게 값 ≥0 인 카드가 **2장 미만**인 상대의 조우 비중 합. 3픽이라 답이 1장이면 못 내는 경기가 생긴다. `11/12/12b` CSV에 `gap_exposure_pct`, `zero_answer_opps` 열로 들어 있다.
- 페이지 기본 추천은 **하나**: 균형값 최고와 0.005 이내 팀 중 무답 노출이 가장 작은 팀.
- **메가스톤 1장이 기본**. 한 경기에 메가는 1회라 두 번째 스톤은 아이템 칸을 죽인다. 아이템 배분도 "실제로 메가하는 한 마리만 스톤"으로 수정(이전엔 메가 가능한 카드를 최대 2장까지 스톤 보유자로 보고 아이템을 안 줬음).
- 정직하게 적어 둘 점: 조합 탐색·내시는 아이템 없이 풀어서 두 번째 스톤의 손해를 모른다 → 2장 최적이 1장 최적보다 높게 나온다. 아이템까지 넣어 재면 차이는 0.0067로 줄어든다.

## 5. 연속기 · 바디프레스 — 버그 (09-21)

- `power100.json` 에는 **1타 위력**만 있었다. 트리플악셀 20(실제 20+40+60=120), 스케일샷·고드름침·록블라스트 25(평균 3.1타 → 77.5, 스킬링크면 5타), 더블윙·드래곤애로 ×2. `config.multiHit=1`.
- **바디프레스**가 공격 스탯으로 계산되고 있었다(실제로는 자기 방어). `config.bodyPress=1`.
- 적합도 거의 불변(ρ50 0.502 → 0.503)이지만 **추천 팀이 또 바뀜** — 트리플악셀 94% 채용인 마스카나가 과소평가돼 있었다.
- 현재 페이지 추천: **마스카나/아머까오/에이스번/플라엣테/드래펄트/저승갓숭**(메가 플라엣테, 균형값 +0.0563, 스톤 1장 최고 +0.0612).

## 6. 기술 추천 — 신규 (09-21)

`code/setopt.mjs`(평가기) + `code/mksets.mjs`(100종 일괄) → `derived/sets_blocks.json`, `csv/15_set_recommend.csv`.

**고르는 규칙**
1. 후보: 그 개체의 실채용 상위 10기 중 **채용 15% 이상**(아이템 하한과 같은 기준).
2. **70% 이상 채용 기술은 고정.** 실전 최다 4기에 값을 못 매기는 기술(변화기·교체기·부가효과기)이나 **회복기**가 있으면 그 칸도 유지.
3. 남은 칸만 메타 100종 상대 점수(조우 가중, 상대 메가 반영)로 고른다.

**세트 단위로 추가한 계산** (팀 모델에는 없음)
- 공격 스탯은 세트의 주 분류 하나에만 투자(`evSet`) — 특수형의 물리기는 무보정.
- 쌓기기는 같은 분류에만 배율(칼춤→물리, 나쁜음모→특수, 철벽→바디프레스). 분류가 안 맞는 쌓기기는 쓰지 않음. 용의춤·나비춤·껍질깨기·고속이동은 속도도 올림.
- 선공기: (n−1)×세트 최대 피해 + 선공기 피해 ≥ HP 인 최소 n으로 "깎다가 마지막 한 방을 먼저" 넣는 경로(양쪽 모두).
- 한방기(오버히트·용성군·리프스톰·사이코부스트 −2, 엄청난힘 −1): 쓸수록 약해지고, 한 번 쓰고 다른 기술로 넘어가는 경로도 봄. 기가임팩트·파괴광선은 반동 턴.
- 모으기 기술(일렉트로빔·메테오빔·솔라빔 등)은 두 턴. 가뭄이면 솔라빔·솔라블레이드는 한 턴.
- 반동 켬(1/3, 파멸의빛·양날박치기 1/2).

**교차 검증**: 이 보정들을 모두 끄고 모델과 같은 조건(전 공격기, 6스탯 252)으로 돌리면 팀 모델 `value()` 와 **최대 차이 0.000000** (`code/setval.mjs`).

**결과**: 99종(메타몽 제외) 중 65종은 실전 최다 4기가 그대로 최선(그중 30종은 고정·유지 칸만으로 4칸이 참), 34종은 한두 칸이 바뀜. 예: 한카리아스 용성군 → 역린(+0.162), 망나뇽 용성군·신속 → 10만볼트·용의파동(+0.118).

**회복기를 유지하는 이유**: 모델이 회복기를 빼자고 하는 경우가 많았는데(무장조·샤미드·가라르야도킹 등), 1:1 턴 경쟁 모델은 위협이 약한 내구형의 내구 값을 0으로 자르기 때문에(`dgate=2`) 회복의 값을 구조적으로 과소평가한다. 그래서 실전 4기에 있는 회복기는 믿지 않고 유지한다.
