# 기본 로직 검토 (gpt-6-astra): 적정성 **partly**

개선됐지만 숨은 세트의 정보 누출, 평가모드 불일치와 교체 상태 초기화가 추천을 왜곡합니다.

1. [high] `engine.value_vs` — 세트별 균형값을 따로 계산해 평균하므로, 숨은 상대 세트를 알고 각각 대응전략을 바꾸는 정보 우위를 부여합니다.
   → 내 전략은 세트 간 공유하고 상대 전략만 세트별로 허용하는 베이지안 계획 게임으로 합산하세요.
2. [high] `pick.switch / engine.simulate` — HP만 전달하고 상태·랭크·필드·구애고정 등을 초기화하므로, 잔류와 교체를 실제 전투 상태에서 비교하지 않습니다.
   → 현재 전투 상태를 입력받아 복제하고, 교체 선택에만 교체 시 초기화·등장 효과를 적용하세요.
3. [high] `sets.Evaluator.score / sets.optimize` — 최종 세트 선택까지 branch=False여서 결정적 누적 규칙에 최적화됩니다. 이후 분기 상성평가가 탈락한 세트를 복구하지 못합니다.
   → 탐색은 유지하되 유형별 상위 세트를 분기 또는 공통 난수 MC로 재평가한 뒤 최종 선택하세요.
4. [medium] `team.TeamSearch.reassign_items / search` — 도구 재배정이 must 카드를 다른 카드로 교체합니다. 이후 재탐색에서는 must 인덱스가 사라져 필수 종까지 제거할 수 있습니다.
   → 재배정에 must를 전달해 해당 카드를 고정하고, 모든 후보에서 필수 카드 포함을 검증하세요.
5. [medium] `pick.advise` — best는 혼합에서 최빈인 순수 조합인데 best_value는 혼합 전체의 균형값입니다. 추천 조합 단독으로는 그 값을 보장하지 않습니다.
   → 혼합 균형값과 best의 최악값을 구분하고, 균형 보장이 필요하면 x에 따라 조합을 표본추출하세요.
6. [medium] `engine.duel_stats / branch_value` — 효용의 ±0.05 문턱으로 승패를 판정해, 턴 제한에서 HP만 조금 앞선 미종료전을 승리로 집계합니다.
   → simulate가 종료 원인과 실제 승패를 별도로 반환하게 하고, 미종료 비율을 승률과 분리하세요.
7. [medium] `engine.duel_stats / simulate` — 동속 순서를 경기당 한 번 정해 매턴 재사용합니다. 쌓기·날씨로 새로 생긴 동속도 초기 tie 검사에서 누락됩니다.
   → 매턴 실제 우선도·스피드가 같을 때 독립 추첨하고, 분기 모드에서도 동속 사건을 확률 처리하세요.
