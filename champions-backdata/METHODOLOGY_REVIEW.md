## M1. 추정 대상(estimand)과 구성 타당도

- **무엇을 추정하는지 정의되어 있지 않습니다.** 팀 값은 다음 선택들을 차례로 합성한 값입니다.

  (1:1 효용 척도) → (정면 60 / 교체 20 / 교체 20 혼합) → (실전 신호 λ = 0.2 볼록 결합) → (½·최선의 답 + ½·최악 카운터 합산) → (20×20 게임 값) → (레플리카 팀 균등 평균)

  각 단계에 관측 대응물이 없어서, +0.2590이 +0.2527보다 "얼마나" 좋은지 해석할 수 없습니다. README도 "승률 예측이 아니다"라고 적었지만, 그렇다면 무엇의 예측인지가 정의되어야 합니다.
- **구성 타당도**: 모델이 최적화하는 양과 사용자가 원하는 양(실전 승률)이 같은 방향으로 움직인다는 증거가 없습니다. 유일한 외부 신호 E는 1:1 층만 검증합니다(→ M2).
- **권고**
  - 추정 대상을 "상대 팀 분포 D 아래에서, 정해진 선출 정책을 따를 때 내 팀의 승률 P(승 | 내 팀, D)"로 명시합니다.
  - 모델 출력(팀 값, 선출 값)을 로지스틱 링크로 실제 승패에 보정할 데이터 경로를 둡니다. 선출 보드에서 결과를 기록하는 방식이면 됩니다.
  - 보정 전까지는 절대값(+0.2590)을 보고하지 말고, 순위와 차이만 보고합니다.

## M2. 검증 설계

### M2-1. 쌍 독립 가정으로 SE 과소추정

- check의 ρ(시뮬, E)는 50종에서 만든 1,014쌍의 순위상관입니다. 쌍들이 종을 공유하므로(한 종이 약 40쌍에 등장) 쌍을 독립으로 보면 안 됩니다.

  | 방법 | SE | 95% 구간 |
  |---|---|---|
  | 쌍 독립 가정(Fisher 근사) | 0.019 | — |
  | README 기재 | "약 0.03" | — |
  | **종 단위 군집 부트스트랩**(종을 복원추출하고 그 사이의 모든 쌍 사용) | **0.049** | **[0.535, 0.722]** |

- README가 버전 간 개선으로 적은 ρ 변화(0.632 → 0.645 → 0.642 → 0.628 → 0.631)는 **모두 이 구간 안의 잡음**입니다. 엔진 수정의 채택 여부를 이 지표로 판단할 수 없습니다.

### M2-2. 기준선 부재

- 논문이라면 "단순한 방법으로는 얼마나 되는가"를 먼저 보여야 합니다. 같은 1,014쌍에서 E와의 순위상관은 다음과 같습니다.

  | 예측자 | ρ(·, E) |
  |---|---|
  | 종족값 합 차이 | 0.168 |
  | 스피드 실능 차이 | 0.055 |
  | 인기(조우 비중) 차이 | −0.018 |
  | **타입 상성**(각자 자속 타입의 최대 배율 차, 한 줄 계산) | **0.515** |
  | **1:1 시뮬레이터** | **0.631** |

- 시뮬레이터 − 타입 기준선 = +0.116, 군집 부트스트랩 95% [+0.005, +0.238]. **겨우 유의**합니다.
- 반면 타입 기준선을 통제한 부분상관 ρ(시뮬, E | 타입) = 0.494라서, 시뮬레이터가 타입 외 정보를 분명히 더합니다.
- 결론: 수천 줄짜리 엔진의 한계 기여는 "있지만 작다". 개선 효과는 기준선 대비 증분으로 보고해야 합니다.

### M2-3. 같은 지표로 반복 조정 (forking paths)

- 엔진 수정의 채택과 기각을 ρ(시뮬, E)로 판단해 왔습니다. 그래서 이 ρ는 더 이상 표본 외 지표가 아닙니다. README의 "표본 외 검증"이라는 표현은 맞지 않습니다.
- E는 행렬의 입력(λ = 0.2 혼합)이면서 검증 기준이기도 합니다(이중 사용). 1:1 층에서는 시뮬만 비교해서 직접 누수는 없습니다. 하지만 λ와 엔진 규칙을 같은 E로 정하면 과적합됩니다.
- **권고**: 종을 두 묶음으로 나눠, 한 묶음에서만 모델을 조정하고 다른 묶음은 최종 보고에만 씁니다(cross-fitting). 또는 시간적으로 떨어진 수집본(다음 시즌)을 검증 전용으로 남깁니다.

### M2-4. LLM 심판은 기준값(ground truth)이 아님

- 20쌍 audit의 18/20은 Wilson 95% 구간이 [0.70, 0.97]입니다.
- README의 개선 서사는 통계적으로 구분되지 않습니다. 17/20 → 20/20의 피셔 정확검정 p = 0.23, 15/20 → 18/20은 p = 0.41입니다.
- 심판 자체의 오류도 확인됐습니다. 메가메타그로스 vs 메가입치트에서 심판이 강철 → 페어리 2배를 빠뜨렸습니다.
- 심판 지시문이 모델과 같은 단순화("명중은 기대값")를 쓰므로, 공통 편향은 원리적으로 잡을 수 없습니다.
- **권고**: 결정적 기준(표준 데미지 계산식)으로 검증(verification)하고, 실전 결과로 타당성 확인(validation)을 하는 두 단계를 분리합니다. 모델 검증·확인(V&V) 문헌의 표준 구분입니다.

### M2-5. 결론 층은 검증되지 않음

- check와 audit은 1:1만 봅니다. 추천을 실제로 결정하는 층(합산식, 선출 게임, 팀 탐색)에는 외부 검증이 전혀 없습니다.
- 추천 팀의 우월성은 모델 자신의 지표로만 확인됩니다. 최적화한 팀이 자기 목적함수에서 이기는 것은 정의상 참이라 **순환 논증**입니다.

## M3. 평균의 오류 (Jensen 부등식)

비선형 연산(KO 판정, max·min, LP 게임 값)의 입력을 먼저 평균하면 E[f(X)] ≠ f(E[X])입니다. 이 모델에는 이런 곳이 세 군데 있습니다.

1. **기대값 모드**: 평균적인 궤적의 결과이지, 결과들의 평균이 아닙니다.
   - 새 명중 규칙은 이를 "최빈 결과로 반올림"하는 방식으로 바꿨을 뿐이라 편향이 남습니다.
   - 확률 모드 대비 평균 오차 0.070, 0.3 넘게 틀리는 쌍이 435쌍 중 26쌍입니다.
   - 분기 방식(MODEL_REVIEW B-1)으로 0.030, 7쌍까지 줄어듭니다.
2. **메가 확률을 먼저 평균**(`pick.matchup`)
   - 상대는 자기 팀의 메가가 누구인지 알고 선출합니다. 보수 행렬 P를 시나리오별로 먼저 평균하면 다음이 성립합니다.

     `Σθ pθ · min_{yθ} xᵀPθyθ ≤ min_y xᵀ(Σθ pθPθ)y`

     즉 게임 값이 **항상 낙관 쪽으로** 치우칩니다.
   - 코드는 비선형 합산 전인 V를 평균하므로 방향이 보장되지는 않습니다.
   - 계산 결과: 추천 파티 vs 메가 후보가 2마리 이상인 레플리카 팀 12개에서,

     | | 값 |
     |---|---|
     | 현재 방식이 보고하는 값 | +0.2502 |
     | 시나리오별 대응을 반영한 값(베이지안 게임 LP) | +0.2267 |
     | 차이 | 평균 +0.024, 최대 +0.079 |
     | 최빈 선출 일치 | 6/12 |
     | 현재 방식 전략의 실제 손해 | 평균 0.011 |

3. **상대 대표 세트 1벌(메도이드)**
   - 세트 분포의 기대값 대신 한 점을 대입(plug-in)합니다. 확정타 문턱처럼 불연속인 함수에서는 편향이 큽니다.
   - 메도이드를 고르는 유사도 가중치(성격 1, 배분 1, 도구 1, 특성 0.5, 기술 2×겹침/4)도 근거가 없습니다.
   - **권고**: 빌드 군집 2~3개를 빈도로 가중한 혼합을 씁니다. 가중치 선택이 결과를 바꾸는지 민감도를 보고합니다.

## M4. 수학적 정식화 (게임 이론)

- **1:1은 열린 루프 계획의 행렬 게임입니다.**
  - 각자 "그냥 때리기 / 쌓기 k회 / 상태이상 먼저 / 기습 없이 / 버티기" 중 하나를 처음에 정하고 끝까지 따릅니다.
  - 실제 전투는 매 턴 상태를 보고 반응하는 닫힌 루프(확장형) 게임입니다. 제한된 전략 공간의 균형값은 원래 게임 값의 근사일 뿐이고, 편향 방향도 알 수 없습니다.
  - 그런데 이 값을 상위 층에서 정확한 "값"처럼 max·min·LP에 넣습니다.
  - **권고**: 대표 매치업에서 작은 확장형 모형(깊이 제한 minimax 또는 몬테카를로 트리 탐색)과 비교해, 계획 게임의 근사 오차를 한 번은 측정합니다.
- **선출 게임의 보수 행렬 P가 오지정되어 있습니다.**
  - `P(a,b) = ½·mean_j max_{i∈a} V + ½·mean_i min_{j∈b} V`는 휴리스틱입니다. HP 소모, 기절 순서, 한 포켓몬이 여럿을 상대하는 제약이 없습니다.
  - 오지정된 P의 균형을 정확히 풀면 **가짜 정밀도**가 생깁니다. 선출 보드의 선출 비율 %가 그 예입니다.
  - HP를 이어 가는 3:3 연속 평가 시제품과 비교하면 20×20 순위상관이 0.68이고, 선출 추천은 10경기 중 3경기만 일치합니다(MODEL_REVIEW C-1).
- **상대 모형**
  - 팀 값은 모든 상대가 내 6마리를 보고 **최소최대 최적 선출**을 한다고 가정합니다. 이는 최악 경우(강건) 기준입니다.
  - 실제 상대는 휴리스틱으로 고르므로 기대값 기준의 최적 팀과 다를 수 있습니다. 두 기준 중 무엇을 원하는지 명시하고, 가능하면 둘 다 보고해야 합니다.
- **메타 정적 가정**
  - 추천 팀은 고정된 상대 분포에 대한 **최선 응답**입니다. 상대 세트·팀은 내 선택에 반응하지 않습니다. 팀 구성 게임의 균형이 아니므로, "최적"은 "현재 스냅숏 메타에 대한 최선 응답"으로 표현해야 합니다.
- **계층 분해의 분리 가능성 가정**
  - 세트(상위 80 상대 평균) → 카드(종당 1~3장) → 팀(레플리카 선출 게임)으로 순서대로 최적화합니다. 이는 목적함수가 층별로 분리된다는 가정입니다.
  - 층마다 상대 모집단도 다릅니다(→ M7).

## M5. 척도와 신호 결합

- **효용 척도가 임의적입니다.**
  - 1:1 값은 승 +0.5~+1 / 패 −0.5~−1이고, KO 경계에서 1만큼 불연속입니다. 이 값에 평균·LP 같은 **간격 척도 연산**을 적용합니다.
  - 단조 변환에 대한 불변성을 시험했습니다. |V|²·sign이나 |V|^0.5·sign에서는 추천 팀이 그대로이지만, **승/패 부호만 남기면 6마리 중 3마리가 바뀝니다**(아머까오, 윈디, 메가입치트가 들어옴). 결론이 HP 여유분이라는 크기 정보에 의존합니다.
- **척도가 다른 두 신호의 볼록 결합**
  - V = 0.8·시뮬 + 0.2·E에서, 시뮬은 HP 기반 효용이고 E는 "(패배 목록 순위 − 승리 목록 순위)/15, ±1로 자름"입니다. 단위가 달라서 λ는 의미 있는 모수가 아닙니다.
  - E는 14%가 ±1에 포화되어 있습니다(목록 밖을 30위로 대체한 검열).
  - op.gg 목록에는 **표본 수나 승률이 없고 순위만** 있습니다. 그래서 E는 매치업 승률의 추정량이 아니고 표본오차도 알 수 없습니다.
  - 인기도 상쇄는 경험적으로 작동합니다(E와 인기 차이의 상관 0.018). 하지만 승리 목록 순위 자체는 상대 인기와 상관이 0.36이고, 50종 중 13종은 자기 자신(동족전)이 승·패 목록 3위 안에 있습니다. 목록이 인기에 크게 끌린다는 뜻입니다.
- **권고**
  - E를 섞기 전에 척도를 맞춥니다(예: E의 분위를 시뮬 V의 분위에 대응). λ는 표본 외 자료로 추정합니다.
  - 장기적으로는 계층 베이즈 모형이 맞습니다. 시뮬을 사전 평균으로 두고, 실제 승패 수를 우도로 씁니다.

- **불확실성의 원천별 크기**(이번에 측정)

  → **표본 불확실성은 작고, 가정(모형) 불확실성이 지배합니다.** 그런데 보고하는 불확실성("±0.0060", "1위 확률 97%")은 표본 쪽만 담고 있어서, 독자에게 과도한 확신을 줍니다.
- **"1위 확률"이라는 이름**
  - 부트스트랩 선택 빈도이지, "이 팀이 진짜 최적일 확률"이 아닙니다. 모형이 맞다는 조건부 값입니다.
  - 탐색에 쓴 표본을 다시 쓰는 문제는, 이번 반분 실험에서 선택이 바뀌지 않아 실제로는 작았습니다.

- **다중 비교와 결정 규칙**: "1위와 2 SE 이내 → 무답 노출이 1%p 작으면 우선"은 임계값이 임의적인 사전식(lexicographic) 규칙입니다. 하나의 목적함수(예: 평균 − κ·위험)로 정의하거나 파레토 집합을 보고하는 편이 정합적입니다.
- **보고 정밀도**: "+0.2590 (±0.0060)"은 소수 넷째 자리까지 보고하지만, 가정만 바꿔도 값이 +0.23~+0.29로 움직입니다(λ 민감도). 유효숫자를 줄이고 민감도 범위를 함께 보고해야 합니다.
