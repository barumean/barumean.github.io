  - 능력치 계산(실능 1,643건 전부 일치), 레벨 50·SP 규칙, PP, 속이기 제한, 종·도구 중복 금지, 메가 1회와 Z 메가, 도구 풀 모두 챔피언스 룰과 맞습니다.
  - 싱글의 "6 → 3 비공개 선출, 첫 선택이 선봉" 구조를 게임으로 푸는 설계도 룰에 잘 맞습니다.
- **룰과 어긋나는 부분**(쉬운 것부터)
  1. **마비 12.5%**: 두 모드 모두 25%로 계산합니다(상수 2개).
  2. **잠듦 분포**: 확률 모드가 본가 분포를 씁니다(1줄).
  3. **외형 변형**: 암컷 모습 등을 기본 종으로 합쳐야 메가진화와 종 중복 판정이 룰대로 됩니다.
  4. **시간 초과는 무승부**: 끝나지 않은 대결은 0으로 봐야 룰에 맞습니다(측정 영향은 없음).
- **룰은 맞지만 빠진 메커니즘**
  - 지구력(영향 최대, 추천 파티 멤버), 급류류, 심술꾸러기·부자유친·하바네로분출(메가 특성)
  - 급소율 단계, 날씨·필드 8턴 도구, 벽과 빛의점토
  - 얼음을 포함한 부가효과 전반. 챔피언스 설명문의 확률을 써야 합니다.
- **구조적 한계**: 싱글 배틀은 교체가 자유로운 3:3인데, 모델은 1:1 결과를 합산합니다. 유턴·재생력·그림자밟기·탈출버튼·레드카드 같은 교체 관련 요소가 모두 모델 밖입니다. 게임 룰 관점에서 가장 큰 차이이고, 3:3 연속 평가(MODEL_REVIEW C-1)가 이 차이를 줄이는 첫 단계입니다.
- **앞으로의 위험**
  - 테라스탈이 도입되면 개체 모델(타입 변경)과 기믹 선택("메가 또는 테라, 배틀당 하나")을 다시 설계해야 합니다.
  - 규정이 바뀔 때마다 기술 수치(PP·명중·부가효과)가 바뀌므로, op.gg 메타 수치보다 게임 설명문과 게임 데이터를 우선하는 검증 단계가 필요합니다.

2. **외형 변형 통합**: `-female` 등을 기본 종으로 합쳐 메가·종 중복 판정 적용. 돌핀맨은 제로폼으로 시작

4. 급류·맹화·심록·벌레의알림, 심술꾸러기, 부자유친, 하바네로분출

6. 부가효과(얼음 3턴 규칙 포함)를 게임 설명문 확률로 구현
7. 교체를 포함한 3:3 평가(구조)

## 부록: 확인 방법

- **능력치 공식**: `replica_teams.json`의 슬롯 중 `baseStats`에 실능치가 저장된 1,643건에서, `calc_stats(도감 종족값, customStats, 성격)`과 정확히 일치하는지 봤습니다. 종족값이 저장된 1,195건은 도감 값과 같았습니다.
- **설명문 대조**: `dex.json`의 기술 설명에서 "N% 확률"을 뽑아 기술 메타(`ailmentChance`, `flinchChance`, `statChance`)와 비교했습니다. 불일치는 7개 기술이었습니다.
- **미구현 특성·도구 비중**: `engine.py` 소스에 키 문자열이 없는 특성·도구를 상대 대표 세트(`opponents()`)의 조우 가중치로 합산했습니다.
- **룰 수정 영향**
  - 엔진 사본에 환경변수로 켜는 수정 5개를 넣었습니다: 마비 0.125, 시간 초과 0, 급류류 1.5배, 지구력, 암컷 메가.
  - 추천 파티 × 상대 345개체와 상위 30종 쌍의 `value()`를 현재 엔진과 비교했습니다. 변화 기준은 |Δ| > 0.05입니다.
- **테라스탈**: 레플리카 팀 슬롯 키가 pokemon·item·ability·nature·moves·baseStats·customStats뿐이고, 테라 타입 칸이 없습니다.
