내 파티 바꾸기

누르면 넣기·빼기(최대 6마리, 같은 종 1마리). 스톤은 여러 마리가 들어도 되고, 둘 이상을 같이 내면 배틀에서 한 마리만 메가진화하는 것으로 계산합니다(상대 3마리를 보고 유리한 쪽). 3마리 이상이면 바로 다시 계산합니다. 세트는 모델이 찾은 종별 최적 세트이고, 순서 = 싱글 순위. 직접 정한 기술·도구로 보려면 python -m champions ui --party 내파티.txt 로 다시 만드세요.

상대 파티 예시

· 누르면 추가·빼기. 타입을 두 개 고르면 두 타입을 모두 가진 포켓몬만 보입니다. 메가가 가능한 칸을 누르면 자동(확률) → 메가 확정 → 메가 아님 순서로 바뀝니다. 목록 순서 = 조우 비중.
